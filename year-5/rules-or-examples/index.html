Curriculum map / Year 5: Data, Training and Fairness

Year 5, Lesson 1

Rules or examples?

Some programs follow rules we write; AI learns from examples.

ILinks: CS

The signature activity

Pupils write a rule-based sorting program in Scratch, then try to beat it with tricky cases a trained model would handle, and vice versa.

Learning intentions

  • I can explain the difference between a rule based program and machine learning.
  • I can write a rule based sorting program and test it with tricky cases.
  • I can say what each way is good at, and where each one falls short.

The slides
