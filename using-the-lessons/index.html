Using the lessons

Using the lessons

Each lesson has one lesson plan and one slide deck. Everything a teacher needs is inside those two files.

Make a copy

On any lesson page, choose Make a copy and the file is copied into your own Google Drive. Your copy is yours to edit.

Download

On Microsoft 365? Download the slides as PowerPoint and the plan as Word instead.

Inside the files

Teacher notes and answers sit in the speaker notes of every slide, and printable resources are at the end of each deck.
